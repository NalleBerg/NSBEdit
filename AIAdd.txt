AI Additions Plan

- Local AI backend, attached through a small localhost bridge service.
- Floating always-on-top window that can be moved, resized, collapsed, and hidden.
- Suggestions mode for code only, with copy / insert / replace handlers.
- Agent mode for code only, where the AI can write code and trigger build/compile.
- Non-intrusive behavior: no modal flow, no blocking typing, no auto-editing without approval.
- No AI services for .rtf, .txt, or clean text documents.
- Code tabs only, with explicit tab-level gating.
- Local context only: active file, selection, nearby lines, and relevant open tabs.
- Build loop integration using the existing makeit.bat / pack.ps1 workflow.
- User approval and diff preview for applied changes.
- Provider abstraction so different local model engines can be swapped later.
