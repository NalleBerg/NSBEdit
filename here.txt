NSBEdit handover notes
Written: 2026-06-23

Current status
- The AI shell is now split into three visible zones again: the model/status summary at the top, the prompt editor and action row in the middle, and the answer pane at the bottom.
- The running timer now shows on the right side of the status line as a live clock, and the frozen result still changes to the last completed duration after the request finishes.
- The answer window scrollbar chrome was removed, so the answer pane itself no longer shows a vertical scrollbar.
- Scintilla code blocks still keep their own sideways scrollbar inside the code block, which is the correct place for horizontal scrolling.
- The current remaining UI problem is that the answer pane still does not consistently present the first code block at the start of the visible region when a reply begins with code and prose follows.
- The first prose block is currently visible again after the last layout pass, but the code block visibility and the initial viewport choice are still the active bug.
- cmark-gfm is linked and the markdown split renderer is still in place; the remaining issue is now layout/viewport selection, not parsing.

What was fixed in this session
- The answer pane no longer draws its own vertical scrollbar.
- The Scintilla code block still keeps its own internal scrollbar.
- The running timer/status text now shows a live elapsed clock.
- The frozen timer text still shows the last completed duration.
- The answer-pane startup scroll no longer jumps to the prose block.

- Verify that Scintilla code blocks still render with the correct lexer and copy-header behavior after the layout change.
